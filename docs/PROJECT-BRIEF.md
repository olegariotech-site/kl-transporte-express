# K.L Transporte Express — Projeto Comercial V1

## Objetivo
Criar uma landing page simples, rápida e orientada à conversão para WhatsApp. Os serviços não possuem preço tabelado; cada solicitação exige nova cotação conforme rota, carga, veículo e condições do serviço.

## Serviços confirmados em canais atuais
- Moto Frete
- Pickup e Fiorino
- Van / Furgão
- Caminhão e Carreta

## Direção comercial
Posicionar a K.L acima de “apenas motoboy”, apresentando capacidade para diferentes portes de entrega e transporte. O CTA principal em toda a experiência é solicitar uma cotação pelo WhatsApp.

## Fluxo de cotação
1. Endereço de coleta
2. Responsável pela retirada
3. Endereço de entrega
4. Responsável pelo recebimento
5. Tipo de mercadoria
6. Peso e dimensões quando aplicável
7. Observações
